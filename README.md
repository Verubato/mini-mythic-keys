# MiniMythicKeys

Simple addon that responds to "!key" and "!keys" messages in party/raid/guild chat with the mythic keystone you have. Also has a "/key" and "/keys" command that opens a window showing all the keystones of your party and guild members.

Useful so you don't have to find the key in your bags, and also so others can find out what key you have without having to ask you.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
